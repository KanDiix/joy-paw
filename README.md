# FunLand

Public site built with React, TypeScript and Vite, available in English and French.

## Getting started

Requires Node 24+ and Yarn (any version: the project pins Yarn 4.18 in `.yarn/releases`).

```
yarn          # install
yarn start    # dev server on http://localhost:3000
```

Other commands: `yarn typecheck`, `yarn lint`, `yarn test`, `yarn build:prod`, `yarn preview`.

See [AGENTS.md](AGENTS.md) for the architecture, the conventions and the planned building blocks.
